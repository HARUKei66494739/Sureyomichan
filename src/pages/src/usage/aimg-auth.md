# aimg API認証について

## API認証とは

aimgで認証が必要な操作をする場合aimgのAPIの認証が必要です。


### 有効期限

21日間です。再度認証することで有効期限の延長が可能です。


## 認証手順

1. アプリを起動し設定を開きます

2. aimgの項に移動し認証ボタンを押します
![-](/images/usage/aimg-auth_010_setting.png)

3. ブラウザが開くので内容を確認し、許可してください
![-](/images/usage/aimg-auth_020_aimg.png)

4. タブはもう使用しないので閉じます
![-](/images/usage/aimg-auth_030_local.png)

5. 認証が成功すると有効期限が表示されます。その後aimgのパスワードを入力して下さい

6. 認証と削除キーが有効化されていると読み上げ画面のdel, 削除ボタンが有効になります。
![-](/images/usage/aimg-auth_040_auth.png)
